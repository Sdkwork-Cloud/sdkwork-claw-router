# mobile-react

Progressively scaffolded mobile React capability packages with the same domain taxonomy.

Grouped domains:

- `foundation`: Application composition, shell, routing, and workspace orchestration.
- `host`: Host abstraction and desktop runtime adapters.
- `system`: Settings, permissions, notification, dashboard, home, and help surfaces.
- `iam`: Tenant, organization, user, authentication, authorization, session, and security capabilities.
- `communication`: Realtime communication, relationships, channels, and social surfaces.
- `intelligence`: AI-first capabilities: chat, models, agents, memory, knowledge, and automation.
- `content`: Content creation, file systems, editors, media, and generated asset workspaces.
- `commerce`: Product, pricing, subscription, billing, wallet, and metered consumption capabilities.
- `device`: Local device, install, packaging, and distribution-aware capabilities.
- `ecosystem`: Ecosystem expansion through plugins and market distribution.
